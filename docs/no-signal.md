# No signal

## Customers may say
- "I can't see my TV."
- "I am unable to see any channels."
- "My TV shows no signal."

## What it means
The customer cannot see any channels. This is usually a no signal problem. The TV or the set-top box is not receiving the signal.

## Before you start
1. Check that the connection is active and not suspended. If it is suspended, explain the suspension to the customer. Do not create a work order for a suspended connection.
2. Check whether the customer already has an open no_signal work order. If yes, tell the customer about it. Do not create another one.

## Steps
Do these steps in order. After each one, check whether the problem is solved.
1. Ask the customer to check the TV input source. It should match the connection used, for example HDMI, AV or AV1.
2. Ask whether the weather is cloudy or rainy. If yes, ask the customer to wait until the weather clears and then check again. If no, continue.
3. Ask the customer to check the cable at the back of the set-top box. If it is loose, ask the customer to tighten it or connect it properly.
4. Check whether the problem is solved. If not, continue.
5. Ask the customer to switch off the power supply, wait for 10 seconds, and then switch it on again.
6. Check again whether the problem is solved. If not, a technician visit is needed. Create a no_signal work order.

## Do not
- Do not create a work order before all the steps are done.
- Do not create a work order for a suspended connection.
- Do not create a second work order if an open no_signal work order already exists.

## What to tell the customer
- Explain each step in simple words and ask the customer to confirm the result.
- Before creating the work order, tell the customer that a technician visit is needed and ask for confirmation.
- After creating it, say that the request is created and the technician time slot will be fixed later.
